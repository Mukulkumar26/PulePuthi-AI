# PulePuthi AI - Meghalaya Education Insights

## Project Overview

PulePuthi AI is an AI-powered educational infrastructure analysis project developed using Python, Google Gemini AI, and Power BI.

The project analyzes district-level education data from Meghalaya and generates actionable policy recommendations to support educational planning and resource allocation.

---

## Objectives

- Analyze student, teacher, and classroom distribution across districts.
- Identify districts requiring infrastructure expansion.
- Generate AI-assisted policy recommendations.
- Visualize key educational indicators using Power BI.

---

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Google Gemini AI
- Power BI
- Microsoft Word Reporting

---

## Dataset

The dataset contains district-level educational information including:

- Number of students
- Number of teachers
- Number of classrooms
- Pre-primary enrollment
- School counts

---

## Key Insights

### Highest Student Population
Ri Bhoi

### Highest Teacher Count
Ri Bhoi

### Highest Pre-Primary Enrollment
East Khasi Hills

### District Requiring Classroom Expansion
West Garo Hills

### Average Student-Teacher Ratio
15.61

---

## AI-Generated Recommendations

- Prioritize classroom expansion in West Garo Hills.
- Strengthen teacher deployment and resource allocation in Ri Bhoi.
- Continue investment in pre-primary education initiatives in East Khasi Hills.
- Maintain student-teacher balance through targeted recruitment and monitoring.
